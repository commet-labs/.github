# Contributing

Thanks for your interest in Commet's open source projects.

## Start with an issue

We review pull requests only for issues a maintainer has approved.

1. Open an issue describing the bug or the change you want to make. Search existing issues first.
2. We discuss it in the issue. If we agree on the change, a maintainer assigns the issue to you.
3. Open a pull request that references it with `Closes #<issue number>` in the description.

Pull requests without a referenced issue assigned to their author are closed automatically. Bug reports, reproductions and ideas are always welcome as issues.
